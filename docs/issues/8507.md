# Issue #8507 — [Western Plaguelands] Issues with Blood of Heroes
state: open, labels: Confirmed, 50-59, DB, Fix included
summary: "Blood of Heroes" gameobjects (176213) in Western/Eastern Plaguelands spawn underground/duplicated in places and a handful of GUIDs (45515, 45513, 45935, 45937, 45854, 45869) have a too-short respawn timer.
status: investigated, skipped -- fix exists but in the wrong schema, would require inventing values to port it
notes: contributor avarishd linked a concrete fix, but it's an external cmangos/classic-db commit (f5bcc75), not AC SQL: https://github.com/cmangos/classic-db/commit/f5bcc75c146d70b3e71f6810e01bf875a8f35be8 -- fetched and inspected the patch directly. It's a full spawn-table rewrite for GO 176213 (roughly 160 rows across both zones), but cmangos's `gameobject` table only carries (guid, id, map, position_x/y/z, orientation, rotation0-3) -- it has no zoneId, areaId, spawnMask, phaseMask, animprogress, state, ScriptName, or VerifiedBuild columns, all of which AC's `gameobject` table requires. Porting this correctly means either inventing those AC-specific column values per row or leaving them at bare defaults across ~160 unfamiliar rows, which is authoring a new fix dressed up as applying an existing one. That crosses the line this sweep is supposed to hold. Skipping until someone posts an AC-schema version.
